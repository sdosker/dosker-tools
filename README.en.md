# Dosker Tools

[Leia em português](README.md)

Editor tools for VRChat creators, distributed as VPM packages for the
[VRChat Creator Companion](https://vcc.docs.vrchat.com/) (VCC). Every window is available in English and Brazilian Portuguese.

## Install

1. Open the listing page: <https://sdosker.github.io/dosker-tools/>.
2. Click **Add to VCC**, or add this address manually in **Settings > Packages > Add Repository**:

   ```text
   https://sdosker.github.io/dosker-tools/index.json
   ```

3. In VCC, open **Manage Project** and add the packages you want.

The windows are in the **Tools > Dosker Tools** menu.

## Language

By default the tools follow your system language, so they open in English unless your system is in Portuguese.
To change it, use **Tools > Dosker Tools > Language**, **Edit > Preferences > Dosker Tools**, or the globe button in any
Dosker window. The choice applies to every installed Dosker package at once.

## Packages

| Package | What it does | License |
|---|---|---|
| ShaderView | Debugs shaders by simulating VRChat cameras and contexts | MIT |
| VRChat Edit-Mode Preview | Shows PhysBones, Contacts and Constraints outside Play mode | MIT |
| Animation Audio Waveform | Shows audio inside the Animation window | MIT |
| Compressor Exclusions | Chooses which parameters VRCFury's compressor may compress and predicts the build result | Non-commercial |
| Performance Budget | Predicts the avatar's rank, taking into account what VRCFury changes during the build | MIT |
| Editor UI | Shared interface, installed as a dependency | MIT |
| All tools | Installs every package at once | See each package |

Compressor Exclusions also needs VRCFury, which must be installed from the [official listing](https://vcc.vrcfury.com).

Detailed documentation is in each package's `README.md`, in Portuguese.
