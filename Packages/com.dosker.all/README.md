# Dosker Tools: todas as ferramentas

Instala de uma vez todas as ferramentas do Dosker Tools. Sozinho, este pacote não adiciona nada: ele só depende dos outros, e cada um continua com a própria versão.

Para instalar só algumas ferramentas, adicione-as individualmente pelo VCC.

## Antes de instalar

- O **Compressor Exclusions** tem licença não comercial, e isso vale também quando ele é instalado por aqui.
- O **Compressor Exclusions** precisa do VRCFury, instalado pelo [listing oficial](https://vcc.vrcfury.com).
- Cada pacote tem a própria licença, descrita no respectivo `LICENSE.md`.
